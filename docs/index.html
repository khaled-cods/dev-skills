Eight skills, each with one clear job

 
You ask in your own words. The right skill loads from the description, and costs nothing when it is not needed.

 






 
Install

 
Pick the way you work.

 

  
Claude Code
One command installs all eight skills. Needs Claude Code 2.1.275 or later.

   
claude plugin install dev-skills --marketplace khaled-cods/dev-skills

  
Claude app
Zip one skill folder and upload it.

   
Settings → Capabilities → Skills
→ Upload skill (zip)

  
Any assistant
They are plain Markdown. Paste a SKILL.md into your custom instructions.

   
skills/<name>/SKILL.md
